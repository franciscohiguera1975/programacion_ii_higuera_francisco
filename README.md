## Descripción

Este repositorio contiene los proyectos, prácticas, ejercicios y actividades desarrolladas durante la asignatura **Programación II**.

La materia está orientada al desarrollo de aplicaciones utilizando **Python**, **Django** y **Odoo**, aplicando conceptos de programación, desarrollo web, bases de datos y arquitectura de aplicaciones.

---

## Tecnologías

### 🐍 Python

**Python** es un lenguaje de programación de alto nivel, interpretado y de propósito general. Se caracteriza por una sintaxis sencilla y clara, lo que facilita el desarrollo de aplicaciones y el aprendizaje de programación.

Durante la materia se trabajarán conceptos como:

* Variables y tipos de datos.
* Operadores.
* Estructuras condicionales.
* Estructuras repetitivas.
* Funciones.
* Colecciones.
* Programación orientada a objetos.
* Manejo de excepciones.
* Módulos y paquetes.
* Manejo de archivos.
* Conexión con bases de datos.

---

### 🌐 Django

**Django** es un framework web desarrollado en Python que permite construir aplicaciones web de manera estructurada, segura y escalable.

Django utiliza el patrón **MVT (Model-View-Template)** y proporciona herramientas para trabajar con bases de datos, usuarios, formularios, rutas y administración de aplicaciones.

Durante la materia se trabajarán conceptos como:

* Creación de proyectos y aplicaciones.
* Modelos y ORM.
* Migraciones.
* Vistas.
* URLs.
* Templates.
* Formularios.
* Administración de Django.
* Autenticación y usuarios.
* Bases de datos.
* Desarrollo de aplicaciones web.

---

### ⚙️ Odoo

**Odoo** es una plataforma de gestión empresarial de código abierto que permite desarrollar y utilizar aplicaciones para diferentes procesos de una organización, como ventas, compras, inventario, contabilidad y recursos humanos.

Odoo está desarrollado principalmente utilizando **Python** y permite extender su funcionalidad mediante módulos.

Durante la materia se trabajarán conceptos como:

* Estructura de un módulo Odoo.
* Modelos.
* Campos.
* Vistas.
* Menús y acciones.
* Seguridad y permisos.
* Relaciones entre modelos.
* Herencia.
* ORM de Odoo.
* Desarrollo de módulos personalizados.
